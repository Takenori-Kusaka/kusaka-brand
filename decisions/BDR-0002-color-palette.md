# BDR-0002: 配色を「藍丹(あいに)」案とし、丹を人が触る場所に限る

## ステータス

採用(2026-10-12)

## コンテキスト

既存のサイトの色(ink `#1f2937`、blue `#24548c`、green `#3a7d5c`、paper `#f8f5ef`)は場当たりで、意味を持たなかった。60 年使う配色を、色彩心理の実証、日本の伝統色、アクセシビリティの科学、OKLCH の道具立てで決めたい(`research/02-color-research.md`)。

## 決定

- 主色は**藍**(和色大辞典の紺色 `#223a70` を基準に、OKLCH の段 800 `#253d73`)。静けさ・信頼の連想が異文化データで最も普遍的(Jonauskaite 2020)で、ジャパンブルーとして職人の技術を指す色
- 合図は**丹**(`#e45e32`)。鳥居・魔除けの境界の色。**人が触る場所(判定・承認・レビュー)にだけ使い、販促・強調に使わない**。朱系は色覚多様性に配慮した赤(CUD の推奨)
- 成長は**千歳緑**(`#316745`)。常緑の変わらぬ緑。丹と並べるときは明度差 0.15 以上と形の併用
- 紙は**生成り**(`#fbfaf5`)、文字は**墨**(`#2a2f3a`、藍の色相を 2% 含む)。純白と純黒は使わない
- 段(50〜950)は OKLCH の明度で固定し、彩度は色相と明度を保ったまま sRGB に入るまで落とす。生成り上で 600 ≥ 4.5:1(AA)、700 ≥ 6:1、800 ≥ 7:1(AAA)を全色相で共通にする(検査 `npm run check`)
- 適合の下限は WCAG 2.2、設計の指針は APCA(Lc 75)。WCAG 3 は草案
- ダークモードは地 `#16181d`、アクセントを 1 段明るく

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| B 勝色(かちいろ)と鉛丹 | 最も煽らない印象で CVD も最良だが、黒に近い主色は「日本人は暗い色を好まない」(Yokosawa 2016)と緊張し、鉛丹は生成りの上で非文字の 3:1 を満たさない |
| C 藍鼠と弁柄 | 侘び寂びで飽きにくいが、識別性が最も弱く、主色と弁柄の明度が同じで互いに載せられない。ダークモードで地と溶ける。**象牙・羊羹の中性色だけを A に取り込んだ** |
| 既存色の継続 | 意味を持たず、green `#3a7d5c` は丹との CVD 分離が弱い(プロタン ΔE 0.055)。link `#24548c` は藍の 700 に近く、継続は可能 |
| 黄・金を主色に | 喜びの連想は普遍だが緯度で変動し、販促の色と混ざる |

## 根拠の水準

- 色と感情の連想: 一次資料で確認(Jonauskaite 2020、Adams & Osgood 1973、Palmer & Schloss 2010)
- 「色が行動を動かす」主張は採らない(効果量が小さく再現性が弱い。Lehmann 2018)
- コントラストと OKLCH の値は自作の実装(`scripts/color-math.mjs`)で算出。oklch.com・Leonardo で再検証する(未実施。暫定)
- 伝統色の hex は出典ごとに違う。和色大辞典を主、DIC を印刷の参照にした

## 影響

- digital-garden の色を置き換える(blue → ai.700、green → growth.700、ink → ink.900)
- 図の中の赤はすべて「人が触る場所」の意味になる。警告・危険には弁柄と黄土を使う
