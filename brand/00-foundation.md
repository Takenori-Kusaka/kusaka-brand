# 00 基盤 ── 誰の、何のためのブランドか

## 1. 一文

> 現場と経営のあいだを翻訳し、判断の前提を揃える設計者。マシンは速い。それでも、決められた場所では必ず人が触る。

## 2. 人物像から属性へ

ブランドは「どう見せたいか」ではなく「どう在るか」から引きます。次の 4 点は、本人の経歴・価値観・生活選好(私有の記録)から取り、公開してよい形に言い換えたものです。

| 在り方 | 由来 | ブランドの属性 |
| --- | --- | --- |
| **現場から始める** | 板金・回路・ファームウェアから始め、クラウドと生成AI へ至った。ないがしろにされてきた現場(製造業、非デスクワーカー)を助けたい | 素朴で本物。飾らない。UD(ユニバーサルデザイン)書体 |
| **翻訳する** | 現場の困りごとを、選択肢・コストの桁・影響範囲として経営へ渡す。トレードオフを桁で示す | 一目でわかる図。事実と解釈を分ける体裁 |
| **誠実に留保する** | 根拠のない断定を嫌う。確かめていないことは「確かめていない」と書く | 根拠水準マーク。煽りの禁止。訂正を公開する |
| **余力を残す** | 燃え尽きの経験から、余力(バッファ)を生き方の原則にした。静けさ、古社、常緑の木 | 余白の多いレイアウト。藍と和紙と常緑。「これでいい」の美学 |

## 3. 声(voice) ── 常に同じもの

「X だが Y ではない」の 4 組で定めます(Shopify 型)。トーン(場面で変えるもの)は `03-voice-and-tone.md`。

| X | だが Y ではない |
| --- | --- |
| 率直 | 冷たくない。断定を相手にぶつけない |
| 根拠を示す | 衒学的でない。出典は添えるが、読者を試さない |
| 静か | 無関心ではない。熱量は、構造と図の精度に出す |
| 翻訳者 | 代弁者ではない。相手の言葉で言い換えるが、相手の立場を演じない |

NN/g の 4 軸での位置(1 回だけ決めて記録する): 形式的 ←●──── 砕けた / 真面目 ●───── 面白い / 敬意 ●───── 不遜 / 淡々 ●───── 熱狂。

## 4. 変えないもの、変えてよいもの

60 年使う前提で、**変えないもの**と**変えてよいもの**を分けます。変えないものを変えるときは、新しい BDR(`decisions/`)で置き換えます。

| 変えない(BDR を要する) | 変えてよい(改訂で済む) |
| --- | --- |
| 声の 4 属性 | 媒体別のトーンの強度 |
| 色の数(主色 1 + 合図 1 + 緑 1 + 紙 + 墨)と、丹を「人が触る場所」に限る規則 | 段の値の微調整(ただし見た目が変わる値変更は major) |
| 書体の系統(UD ゴシック + Noto + 同系の等幅)と「本文とコードを同族で揃える」方針 | 具体的な書体ファイルの版、Web フォントの配信方法 |
| 意味別の体裁の体系(事実・解釈・暫定・引用・規範・コード) | 体裁の記法(Markdown か HTML か) |
| 斜体を使わない、太字は UI 専用、煽りを書かない | 用字用語の個別の語 |
| 図の 3 層(キービジュアル・節図・構成図)と「主ラベル ≥ 幅/32」 | 描画器の実装(resvg → 別のラスタライザ) |

## 5. 先例から借りたもの

- IBM(1956〜): 原則を正本にし、テンプレートを生成物にする。「固定のテンプレートは古びる」
- 無印良品: 「これがいい」ではなく「これでいい」。空っぽの器
- Vignelli: Timelessness と Equity(変更のための変更をしない)
- Rams: Good design is as little design as possible
- 公用文作成の考え方(文化庁 2022)、JLReq(W3C)、デジタル庁デザインシステム、SmartHR Design System: 日本語の組版と用字用語の現行の実務

根拠の調査は `research/01-brand-systems-survey.md`。
