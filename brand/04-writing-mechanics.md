# 04 用字用語 ── 迷ったときの決まり

機械で検査できるものは textlint(preset-ja-technical-writing)と publishing-hub の用語辞書(`lint/terms/*.yaml`)に降ろしています。ここは、その判断の基準です。SmartHR Design System と公用文作成の考え方(文化庁 2022)を手本にし、既存の原稿の多数派を優先します。

## 1. 漢字とかな

| 書く | 書かない | 理由 |
| --- | --- | --- |
| すべて、とくに、ただし、あらかじめ、さらに | 全て、特に、但し、予め、更に | 副詞・接続詞はかな(既存の原稿の多数派) |
| できる、わかる、いう | 出来る、分かる(表外読みでないが)、言う(「〜という」) | 補助的な動詞はかな |
| 1つ、2か所、3か月 | 一つ、2ヶ所、3ヵ月 | 数えられるものは算用数字。「か」はかな(公用文) |
| 常用漢字表の範囲 | 表外漢字、表外読み(想い、旧い) | 読み手に配慮。固有名詞は除く |

## 2. カタカナ語

- -er / -or / -ar は長音を付ける(ユーザー、サーバー、フィルター)。ただし既存の辞書で長音なしに固定した語(レビュア、アダプタ)はそれに従う
- -y は長音なし(セキュリティ、プロパティ)
- 先に漢字語での言い換えを考える(「アサイン」→「割り当て」、「フィックス」→「修正」)
- 固有名詞は英字の正式名(GitHub、Claude Code、Qiita、note)。商標記号は付けない

## 3. 数字と単位

- 半角の算用数字。4 桁以上はコンマ(1,600 字)。兆・億・万は漢字(2,000 万円)
- 数字と助数詞は密着(3つ、2024年、5GB、10 件は「10件」。ただし既存の原稿が「10 件」で統一しているリポジトリでは辞書に従う)
- 範囲は「〜」(18〜20名)
- 日付は 2026-10-12(機械が読む文脈)か 2026年10月12日(本文)。時刻は 24 時間制
- 「%」は半角、前後にアキなし(0%)

## 4. 記号

| 記号 | 使い方 |
| --- | --- |
| 、。 | 句読点。「，．」は使わない |
| （）「」『』［］【】 | 補足 / 引用・強調・ファイル名・画面の文言 / 「」の中 / UI のラベル / 項目の見出し |
| ・ ／ ： | 全角、前後にアキなし |
| ── | ダッシュ(U+2500 × 2)。副題の区切りは「 ― 」(U+2015)。「—」(U+2014)は使わない |
| ！？ | 原則使わない。使うなら全角で直後に全角スペース |
| `` ` `` | コード、ファイル名、コマンド、識別子 |
| → | 本文に書かない。図の矢印は図で |

## 5. 固有名詞と略語

- 初出でフルスペルか言い換え: 「AIDLC(AI-Driven Development Life Cycle)」「結果責任(A)」
- 「日本語(英字)」の順(個人(P)、判断記録(ADR))
- 略語は全大文字(RACI、PoC、CI/CD)
- 自分の作品の題名は書き換えずに引用する(publishing-hub V11)

## 6. 文

- 1 文 100 字まで。読点は 3 つまで
- 同じ助詞を 1 文で 2 回使わない(「〜が〜が」)
- 二重否定を避ける
- 主語を省ける文は省く。省けない文は「本標準」「本書」「私」のどれかを立てる
- 「〜することができる」は「〜できる」。「〜ということ」は削る
- 「べき」を規範語として使わない(`02-typography.md` 5 節)
